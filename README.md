
# Python Password Generator

A simple command-line password generator built with Python. It generates random passwords using letters, numbers, and special symbols with Python's `secrets` module.

## Features

- Generates random passwords
- Allows users to choose password length
- Includes uppercase and lowercase letters
- Includes numbers and special symbols
- Checks for invalid password length
- Handles invalid user input
- Uses the `secrets` module for secure random selection

## Requirements

- Python 3
- No external libraries required

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code or a terminal.
3. Run the following command:

   ```bash
   python password_generator.py
   ```

   On Windows, you can also try:

   ```bash
   py password_generator.py
   ```

4. Enter the desired password length.
5. Your generated password will appear in the terminal.

## Python Concepts Used

- Variables and data types
- User input and output
- `secrets` module
- `string` module
- Loops and string operations
- Conditional statements
- Exception handling

Beginner-friendly Python command-line project for learning password generation and secure random selection.
